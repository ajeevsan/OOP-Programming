Bullet Points
1. Object orientaed programming lets you extend a program without having to touch previously tested, working code.
2. All java code is defined in a class.
3. A class describes how to make an object of that class type. A clas is like a blueprint.
4. An object can take care of itself; you don't have to know or care how the object does it.
5. An object knows things and does things.
6. Things an object knows about itself are called instance varibles. They represent the state of an object.
7. Things an object does are called methods. They represent the behavior of an object.
8. When you create a class, you may also want to create a seperate test calss that you'll use to create objects of your new class type.
9. A class can inherit instance variables and methods from a more abstract superclass.
10. At runtime, a java program is nothing more than objects "talking: to other objects.
